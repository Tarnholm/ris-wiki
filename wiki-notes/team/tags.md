# Region tag reference

[← all regions](/Tarnholm/ris-wiki/wiki/regions) · [wiki index](/Tarnholm/ris-wiki/wiki/README)

A region page lists what the region *is* — its terrain, climate, water source, harbour, recruitment
zones, homeland and fertility. These pages say what each of those **does**.

| Reference | What it decides |
|---|---|
| [Terrain](/Tarnholm/ris-wiki/wiki/tags-terrain) | which land-use chains a region allows |
| [Climate](/Tarnholm/ris-wiki/wiki/tags-climate) | the farming level rainfed farming gives |
| [Water sources](/Tarnholm/ris-wiki/wiki/tags-irrigation) | river, lake, springs, oasis or aquifer, and what each unlocks |
| [Ports](/Tarnholm/ris-wiki/wiki/tags-ports) | how far up the port chain a coast lets you build |
| [Recruitment zones](/Tarnholm/ris-wiki/wiki/tags-recruitment-zones) | local troops, per zone, with every region in it |
| [Specialty recruitment](/Tarnholm/ris-wiki/wiki/tags-specialty-recruitment) | the five zones that mark a soldier, not a place |
| [Other recruitment tags](/Tarnholm/ris-wiki/wiki/tags-recruitment-other) | the other region markers recruitment checks (Ptolemaic, Seleucid) |
| [Cultural homelands](/Tarnholm/ris-wiki/wiki/tags-cultural-homeland) | which region is whose, and what that permits |
| [River trade](/Tarnholm/ris-wiki/wiki/tags-hazards-and-river-trade) | which regions lie on a navigable river |
| [Fertility](/Tarnholm/ris-wiki/wiki/tags-fertility) | farmland quality, 1–14 |
