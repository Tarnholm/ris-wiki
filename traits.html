Character traits

← wiki index · all factions · all units

Characters in RTR: Imperium Surrectum are shaped by 3,846 visible traits — the virtues, vices, offices, wounds, habits and reputations that appear on a general's, governor's or agent's scroll. Behind them the file also declares 128 hidden bookkeeping traits the player never sees; they are counted here and excluded everywhere else.

What counts as a trait a player sees — the tests that were measured

The file declares 3,974 traits. Four candidate tests for "the player sees this" were measured rather than assumed:

Every level of every trait has a display name in the text files — the file is generated from a spreadsheet, machinery included — so the name test selects nothing. Requiring an Effect line drops real display-only traits (epithets, titles); requiring a trigger drops everything granted by the campaign script or at birth. The Hidden flag is the mod's own marker for what the player never sees, and it is the test these pages use: 3,846 visible, 128 hidden.

How traits work

  • A trait is a ladder of levels. Points accumulate through triggers — battles fought,

turns idle, buildings raised — and each level shows once its points reach that level's threshold. The 3,846 visible traits carry 5,390 levels between them, fed by 14,297 triggers and 25,631 award rules.

  • Traits pull against each other. 2,340 of the visible traits name anti-traits: points in

one drain the other, so a character drifts toward drink or sobriety, courage or cowardice, never both.

  • 870 traits can pass from father to son at birth.
  • 1,063 trait levels grant an epithet — the "the Great" and "the Mad" a name carries.
  • Some traits are one-way: past a NoGoingBackLevel, the ladder no longer goes down.

Where these answers come from

export_descr_character_traits.txt declares every trait, level, effect and trigger; display names and descriptions are text/export_vnvs.txt (UTF-16LE), keyed by level name. Effect attribute names (Command, Troop Morale, …) are the engine's own UI strings and exist in no mod text file, so they are rendered from the token. Values are printed exactly as the file gives them — movement points as points, never converted to percentages. Where a description has no text entry the page says not determined rather than inventing one.
